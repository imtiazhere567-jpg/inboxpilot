Settings

Connect the systems the agent talks to. Values are encrypted at rest and never shown again once saved. Blank = use the server's environment value, if any.
Mode
Company
Shown in the sidebar and top bar. The operations inbox address is the one the agent watches.
Claude (Anthropic)
Without a key the agent runs a keyword stand-in ("fake model"). With one, Claude reads, classifies, extracts, verifies, drafts and answers. Console: platform.claude.com → API keys. A full 30-email run costs a few cents.
Gmail inbox
Use a dedicated Gmail account. Turn on 2-Step Verification, then Google Account → Security → App passwords → create one for "Mail" and paste the 16-character password. The agent reads via IMAP and moves processed mail to ops-agent/processed.
Slack
api.slack.com/apps → Create app → OAuth & Permissions → bot scopes chat:write, chat:write.public → Install → copy the xoxb- token. Messages carry reference numbers only, never customer contact details.
HubSpot
Disputes become tickets on the customer's company. developers.hubspot.com → test account → Settings → Integrations → Private apps → scopes tickets read/write, companies read/write → token.
QuickBooks Online
Approved invoices become bills. developer.intuit.com → app → Keys & credentials (Development) → OAuth 2.0 Playground: authorise the sandbox company, copy the refresh token and realm id.
Rules sheet (Google)
Optional. Thresholds live in the rules table by default; connect a Google Sheet (columns key, value, note — paste seed/rules.csv) so a non-developer can edit them. Share the sheet with the service-account email as Editor and paste the JSON key file here.
